Meanwhile

Privacy Policy

Last updated 4 August 2026

Meanwhile makes exactly one network call, ever: when you paste your licence key. There is no analytics, no tracking, no telemetry, no update check and no crash reporting. Your code and your agent transcripts never leave your machine.

Who I am

Meanwhile is made and sold by Ngoc Hien Dinh, an individual software developer based in Vietnam. For any question about this policy or about your data, write to hiendinhngoc@gmail.com.

What the app reads on your Mac

To show you what your agent is doing, Meanwhile reads two things locally:

  • a small state file that Claude Code's hooks write to ~/.meanwhile/state.json, recording whether a run started or stopped;
  • the tail of your Claude Code transcript, to name the tool the agent is currently running — for example "reading SPEC.md".

Both are read on your machine and stay there. Meanwhile never uploads, copies or transmits your transcripts, your prompts, your source code or your file names anywhere.

The one network request

When you paste a licence key and activate it, Meanwhile makes a single HTTPS request to Lemon Squeezy's licence API at api.lemonsqueezy.com/v1/licenses/activate. That request contains exactly two values:

  • the licence key you pasted;
  • the fixed text Meanwhile on this Mac, used as the activation's name.

It sends no device identifier, no serial number, no hardware fingerprint, no email address, no username and no usage data. As with any HTTPS request, Lemon Squeezy's servers will see the originating IP address; that is a property of the internet, not something Meanwhile adds. Lemon Squeezy's handling of that request is governed by their own privacy policy.

The app makes this request once. If it succeeds, or if it fails, Meanwhile records that the attempt happened and does not try again on that installation.

What is stored on your Mac

Meanwhile keeps three small files in ~/.meanwhile/:

  • state.json — the current run state written by the Claude Code hook;
  • trial.plist — the date your 14-day trial started;
  • license.json — after activation, the activation identifier Lemon Squeezy returned, so the app knows it is licensed.

These never leave your machine. Deleting the ~/.meanwhile folder deletes all of them. There is no account, no server-side profile and nothing for me to delete on your behalf, because I never receive any of it.
