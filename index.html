How it works

Six seconds into a run, a full-screen overlay appears showing what the agent is doing and how long it has been going. Six seconds, because a takeover on every three-second reply gets uninstalled.

To leave, you have to hold for two seconds. When the agent finishes, the overlay vanishes and you're exactly where you were.

After five minutes Meanwhile gives the machine back — the overlay steps aside and the menu bar carries the run instead, so a long job doesn't hold a screen you're no longer waiting at. If the agent finishes while you're elsewhere, you get a notification.

The screen it shows is deliberately plain. No calendar, no news, no now-playing. The whole point is that there is nothing on it worth staying for.

Installing

Download the .dmg, drag Meanwhile to Applications, and launch it. It lives in the menu bar — there is no dock icon and no window.

On first launch Meanwhile shows you the exact thirteen lines it wants to add to ~/.claude/settings.json and installs them on one click. The change takes effect mid-session; Claude Code does not need restarting. Give it a task that takes more than six seconds.

To remove it, choose Remove Meanwhile from the menu bar before dragging the app to the Trash — that takes the hooks back out and leaves your other hooks alone.
